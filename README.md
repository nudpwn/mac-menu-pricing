## 右键菜单里到底多了什么

这部分是判断值不值的核心，我按使用场景拆开讲。

**新建文件。** 访达右键默认只能新建文件夹，想建一个 TXT 或者 Markdown，得先打开编辑器再另存到目标目录。Menuist 直接给了“新建文件”，而且支持导入自己的模板。周报模板、会议纪要模板、固定尺寸的海报文件，设一次以后右键就出来。

**复制路径和文件名。** 复制完整路径，或者只复制文件名。写脚本、往工单里贴路径、在终端里 cd 到某个目录，这类动作每天都得做几次。

**剪切。** macOS 访达没有 ⌘X 剪切，这是老问题了。Menuist 补上了剪切粘贴，另外还有“移动到指定文件夹”和“复制到指定文件夹”两个独立菜单项。

**删除和锁定。** 不进废纸篓直接删，省掉一次清空。锁定文件，防止手滑改掉不该改的东西。

**快捷方式。** 一键生成别名或者硬链接，把常用的深层目录文件直接丢到桌面。

**图标和图片。** 右键改文件夹图标颜色，按项目或者素材类型分色。图片格式转换、把剪贴板里的图片直接粘进当前文件夹、去掉照片的 EXIF 信息，都在右键里。

**预览。** 碰到 .app 文件按空格，能看到软件架构和系统版本要求，装之前就知道这个包能不能在自己机器上跑。QuickLook 还支持代码语法高亮和 .icon 文件预览。

**局域网分享。** 生成一个二维码，同一网络下对方扫码自己拿文件。

**Git 仓库。** 在仓库目录里右键，能直接打开远程地址。

菜单栏那边还有半个文件管理器，放收藏的文件夹、最近访问过的路径、书签站点、常用编辑器和终端命令，外接硬盘也挂在里面。每一项菜单都能隐藏、调顺序，或者指向你自己写的脚本。
